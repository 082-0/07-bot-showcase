# Sakura Privacy Policy

Last updated: 31 October 2026

This policy explains what data the Sakura Discord bot ("Sakura") collects, why, and how you can ask for it to be deleted. Sakura is run by 08, Discord `meatforlove` ("I", "me").

## 1. What Sakura stores

Sakura only stores data it needs to run its features in a server where it was added. Depending on which features a server turns on, this can include:

- **Discord IDs:** user IDs, server IDs, channel IDs, and role IDs.
- **Public profile details:** usernames and display names, shown in logs, tickets, leaderboards, and welcome cards.
- **Server settings:** welcome text, role panels, ticket setup, guard rules, log channels, and similar choices made by server staff.
- **Levels:** XP, rank, and the time of your last XP gain. Message text is not stored for this.
- **Invites:** which invite a member joined with, when Discord data shows it.
- **Moderation records:** bans, kicks, timeouts, mutes, and saved blackouts (these are checked again if the person rejoins), and guard incident records.
- **Tickets:** the messages, attachments links, and details of support and purchase tickets, and a saved transcript when a ticket is closed.
- **Deleted-message logs:** when a message is deleted and Sakura could see it, the text of the message can be posted to a private staff log channel chosen by that server.
- **Away reasons, giveaway entries, and activity history** for features that use them.

Sakura reads messages in channels it can see, so it can run commands, give XP, and log events. It does not sell this data and does not use it for ads.

Sakura does not record, store, or play voice audio. It can stay in a voice channel muted and deafened.

## 2. How data is used

I use the data only to run Sakura's features: setup, tickets, moderation, logs, levels, and the owner's Control Room. I also use it to find and fix bugs and to stop abuse.

## 3. Where data is kept

- Bot data is kept in a database (Supabase).
- The bot runs on a hosting service (Wispbyte).
- The private Control Room and the ticket transcript site run on Cloudflare.

These services process the data for me. I do not share your data with anyone else, except when the law requires it.

## 4. Ticket transcripts

Each closed ticket has a private, unlisted link on the transcript website. The link is sent to the member and to staff channels chosen by the server. Anyone who has the link can read the transcript. Do not share the link.

## 5. Who can see the data

- **Server staff** can see logs, tickets, and moderation records for their own server.
- **The operator (me)** can see stored data through the private Control Room. I only look at it to run and fix the bot, or to handle abuse and requests under this policy.
- Other servers cannot see your server's data.

## 6. How long data is kept

Data is kept while Sakura is in the server and the feature is in use. When Sakura is removed from a server, or when a deletion request is approved, I delete the data for that server or user as soon as I reasonably can. Some data may stay in backups for a short time before it is overwritten.

## 7. Your choices

You can ask me to:

- tell you what data Sakura has about you;
- delete the data about you (for example XP, tickets, or transcripts);
- delete all data about a server (server owners only).

Contact me on Discord (`meatforlove`). I may need to confirm who you are first. Server staff keep control of logs and tickets in their server, so I may ask them to take part in a request.

You can also stop most collection by leaving the server or by asking the server owner to remove Sakura.

## 8. Children

Sakura is for people who are old enough to use Discord (13 or older). I do not knowingly keep data from anyone under that age. If you think I do, contact me and I will delete it.

## 9. Security

I take reasonable steps to protect data. Control Room access is limited to the owner and approved developers, and the bot connects to it with secret keys. No system is fully secure, so I cannot promise that data will never be exposed.

## 10. Changes

I may change this policy. The "Last updated" date will change when I do.
