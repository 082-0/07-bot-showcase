Sakura is a Discord bot you can set up your way. Start with `$setup` to pick your welcome flow, roles, tickets, logs, voice rooms, and moderation tools. Need a hand? `$help` is always there.

I started with the base of another popular all-in-one bot, changed parts of it, and added my own features and Sakura look. This page is for the bot and its design, not its source code.

Soft pink blossoms, a dark night sky, and a little edge. Sakura's profile keeps the gentle side up front; her server tools are there when things get messy. Server owners can also choose their own accent color for supported bot panels.

## What Sakura can do

- **Set up a server:** Build roles and channels, configure welcome messages, verification, rules, and automatic join roles.
- **Give members a place:** Set up color and ping roles, temporary voice rooms, levels, ranks, and giveaways.
- **Handle tickets:** Run support and purchase ticket panels with staff replies and separate archives. Members receive a private transcript link when a ticket closes.
- **Keep things in order:** Use moderation commands, a server guard, configurable event logs, and Discord AutoMod event logs. Server staff can choose to enable Sakura's spam-blocking AutoMod rule with `/automod enable`.
- **Stay in control:** Use the private Control Room for server settings, ticket work, bot presence, and voice controls.

Features depend on the bot's permissions in each server. The Control Room is private and is not part of this public repository.
